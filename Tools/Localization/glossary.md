# Foundation 14 Translation Glossary

Foundation 14 is an SCP Foundation build based on Space Station 14 technology and upstream content.
Fork-owned content should read as Foundation/SCP content, not as generic space-station content.
Upstream strings may still describe a station, crew, cargo, or departments; keep that context when the source text is clearly upstream SS14 content.

Keep technical IDs, prototype IDs, variables, rich-text tags, and SCP designations unchanged.
